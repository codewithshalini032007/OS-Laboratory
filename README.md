# OS-Laboratory
# Basics of Unix Commands

## Aim
To study and execute basic Unix/Linux commands.

## Commands Covered
- pwd
- ls
- mkdir
- cd
- touch
- cat
- cp
- mv
- rm
- rmdir
- clear
- whoami
- date
- wc
- man

## Requirements
- Linux / Ubuntu
- Terminal

## How to Run
Open the terminal and execute the required Unix command.

Example:

```bash
pwd
ls
mkdir test
cd test
